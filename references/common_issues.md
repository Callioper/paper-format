# 常见格式问题与已知限制

## TOP 10 常见格式问题

| 排名 | 问题 | 频率 | 严重度 | 说明 |
|------|------|------|--------|------|
| 1 | 页边距设置错误 | 极高 | P1 | 最常见问题。标准要求：上28mm 下22mm 左30mm 右20mm |
| 2 | 正文字体/字号不符 | 极高 | P1 | 中文宋体小四(12pt)，英文 Times New Roman 小四 |
| 3 | 行距不正确 | 高 | P1 | 应为1.5倍行距，常见错误：单倍行距或固定值 |
| 4 | 首行缩进不规范 | 高 | P2 | 应为2字符缩进，常见错误：使用空格缩进或缩进量不对 |
| 5 | 标题字号层级错乱 | 高 | P1 | 一级16pt黑体、二级15pt黑体、三级14pt黑体、四级12pt黑体 |
| 6 | 参考文献格式不统一 | 高 | P2 | 混用不同引用格式，缺少文献类型标识[M][J][D]等 |
| 7 | 摘要格式不规范 | 中 | P2 | 标题应居中黑体三号，正文宋体小四，关键词加粗 |
| 8 | 表格非三线表 | 中 | P2 | 应仅保留顶线(1.5pt)+底线(1.5pt)+表头底线(1pt) |
| 9 | 目录格式错误 | 中 | P2 | 标题应居中黑体三号，条目宋体四号 |
| 10 | 页眉页脚格式不统一 | 低 | P3 | 页眉字号应为五号(10.5pt)，页码居中 |

## python-docx 已知限制

### 无法自动修复的项目

| 项目 | 原因 | 替代方案 |
|------|------|----------|
| 页眉横线 | python-docx 不直接支持段落边框操作 | 需通过 XML 手动操作 `w:pBdr` |
| 目录更新 | TOC 域代码需要 Word 刷新 | 打开文档后 Ctrl+A → F9 |
| 图片精确位置 | 浮动图片的锚点定位复杂 | 手动在 Word 中调整 |
| 公式编号 | 公式编辑器的对象无法被 python-docx 识别 | 手动添加编号 |
| 文本框内容 | python-docx 不支持文本框读取 | 手动检查 |
| 艺术字/SmartArt | 无法被 python-docx 操作 | 手动调整 |
| 分栏布局 | 部分分栏设置需要手动操作 | 手动在 Word 中调整 |

### 检测精度说明

| 检测项 | 精度 | 说明 |
|--------|------|------|
| 页边距 | 高 | 直接读取 section 属性 |
| 字体/字号 | 高 | 样式级别和 run 级别均可读取 |
| 行距 | 中 | 段落级覆盖可能与样式不一致 |
| 首行缩进 | 中 | 需要区分字符单位和厘米单位 |
| 表格边框 | 高 | 通过 XML 解析 tblBorders |
| 页眉页脚 | 中 | 可读取文本内容，但横线等格式需 XML |
| 标题层级 | 高 | 通过样式名称识别 Heading 1-4 |

## 修复优先级建议

### 必须修复（P1）
- 页边距错误 → 直接影响打印和装订
- 字体/字号错误 → 最基本的格式要求
- 行距错误 → 影响阅读体验和排版美观
- 标题字号错误 → 体现论文结构层级

### 应当修复（P2）
- 首行缩进 → 学术规范要求
- 参考文献格式 → 影响学术规范性
- 表格格式 → 三线表是学术论文标准
- 摘要格式 → 门面工程

### 建议修复（P3）
- 页眉页脚 → 部分学校不严格要求
- 标点符号 → 全角/半角混用不影响理解
- 致谢/附录格式 → 非核心检查项
