# 常见格式问题与已知限制

## TOP 10 常见格式问题

| 排名 | 问题 | 频率 | 严重度 | 说明 |
|------|------|------|--------|------|
| 1 | 页边距设置错误 | 极高 | P1 | 最常见问题。标准要求：上28mm 下22mm 左30mm 右20mm |
| 2 | 正文字体/字号不符 | 极高 | P1 | 中文宋体小四(12pt)，英文 Times New Roman 小四 |
| 3 | 行距不正确 | 高 | P1 | 应为1.5倍行距，常见错误：单倍行距或固定值 |
| 4 | 首行缩进不规范 | 高 | P2 | 应为2字符缩进，常见错误：使用空格缩进或缩进量不对 |
| 5 | 标题字号层级错乱 | 高 | P1 | 一级16pt黑体、二级15pt黑体、三级14pt黑体、四级12pt黑体 |
| 6 | 参考文献格式不统一 | 高 | P2 | 混用不同引用格式，缺少文献类型标识[M][J][D]等 |
| 7 | 摘要格式不规范 | 中 | P2 | 标题应居中黑体三号，正文宋体小四，关键词加粗 |
| 8 | 表格非三线表 | 中 | P2 | 应仅保留顶线(1.5pt)+底线(1.5pt)+表头底线(1pt) |
| 9 | 目录格式错误 | 中 | P2 | 标题应居中黑体三号，条目宋体四号 |
| 10 | 页眉页脚格式不统一 | 低 | P3 | 页眉字号应为五号(10.5pt)，页码居中 |

## python-docx 已知限制与 XML 级解决方案

### 可通过 XML 操作修复的项目

python-docx 高层 API 不支持以下操作，但可通过 `doc.element` 直接操作底层 XML 修复：

| 项目 | 原因 | XML 修复方式 |
|------|------|-------------|
| 页眉横线 | python-docx 不直接支持段落边框操作 | 操作页眉段落的 `w:pBdr` 元素，删除 `w:bottom` 边框 |
| 文本框内容 | python-docx 不支持文本框读写 | 直接读写 `w:txbxContent` 中的段落和 run |
| 公式识别/编号 | python-docx 无法识别 `m:oMath` 元素 | 检测并操作 `m:oMath` 元素；用 `formula.py` 插入带编号的公式块 |
| 表格精确边框 | `tbl.style` 无法精确控制每条边框 | 操作 `w:tblBorders` 中各边框的 `w:val`/`w:size` 属性 |
| 标题中英文混字体 | python-docx 只设一种字体 | 分别设置 `w:rFonts` 的 `w:ascii`/`w:eastAsia`/`w:hAnsi` 属性 |

### 仍需人工处理的项目

| 项目 | 原因 | 替代方案 |
|------|------|----------|
| 目录更新 | TOC 域代码需要 Word 刷新 | 打开文档后 Ctrl+A → F9 |
| 图片精确位置 | 浮动图片的锚点定位复杂 | 手动在 Word 中调整 |
| 艺术字/SmartArt | 无法被 python-docx 或 XML 简单操作 | 手动调整 |
| 分栏布局 | 部分分栏设置需要手动操作 | 手动在 Word 中调整 |

### 检测精度说明

| 检测项 | 精度 | 说明 |
|--------|------|------|
| 页边距 | 高 | 直接读取 section 属性 |
| 字体/字号 | 高 | 样式级别和 run 级别均可读取 |
| 行距 | 中 | 段落级覆盖可能与样式不一致 |
| 首行缩进 | 中 | 需要区分字符单位和厘米单位 |
| 表格边框 | 高 | 通过 XML 解析 tblBorders |
| 页眉页脚 | 中 | 可读取文本内容，但横线等格式需 XML |
| 标题层级 | 高 | 通过样式名称识别 Heading 1-4 |

## 修复优先级建议

### 必须修复（P1）
- 页边距错误 → 直接影响打印和装订
- 字体/字号错误 → 最基本的格式要求
- 行距错误 → 影响阅读体验和排版美观
- 标题字号错误 → 体现论文结构层级

### 应当修复（P2）
- 首行缩进 → 学术规范要求
- 参考文献格式 → 影响学术规范性
- 表格格式 → 三线表是学术论文标准
- 摘要格式 → 门面工程

### 建议修复（P3）
- 页眉页脚 → 部分学校不严格要求
- 标点符号 → 全角/半角混用不影响理解
- 致谢/附录格式 → 非核心检查项

## 中英文符号常见问题（TOP 15）

符号审查是默认步骤，即使用户只说"排版"也要做。以下按出现频率排序：

| 排名 | 问题 | 频率 | 典型场景 | 修正方式 |
|------|------|------|---------|---------|
| 1 | 中文句子里混用英文半角逗号/句号 | 极高 | 复制粘贴英文文献时带入 | 替换为全角中文标点 |
| 2 | 英文术语/文献信息里混用中文全角标点 | 高 | 在中文输入法下输入英文内容 | 替换为半角英文标点 |
| 3 | 中英文之间缺少空格或多余空格 | 高 | 排版规范不一致 | 中英文间加一个半角空格，去除多余空格 |
| 4 | 括号/引号左右不配对或类型不一致 | 中 | 左中文括号配右英文括号 | 统一为同类型 |
| 5 | 破折号/连接号/减号混用 | 中 | 标题中用两个短横线代替破折号 | 破折号用——，连接号用– |
| 6 | 全角/半角数字混用 | 中 | 中文语境下部分数字为全角 | 统一为半角数字 |
| 7 | 引号方向错误或样式不统一 | 中 | 直角引号与弯引号混用 | 统一为一种样式 |
| 8 | 参考文献中冒号/逗号风格不统一 | 中 | 中英文文献混排时标点风格各异 | 中文文献用中文标点，英文文献用英文标点 |
| 9 | 冒号后多余空格或缺少空格 | 低 | 英文冒号后习惯加空格，中文不加 | 按语境区分 |
| 10 | 游离空格（括号/脚注前后） | 低 | 复制粘贴残留 | 删除多余空格 |
| 11 | 英文标题大小写不规范 | 低 | 缺少首字母大写或全大写 | 按期刊/学校规范调整 |
| 12 | 省略号格式不统一 | 低 | 用三个句号代替标准省略号 | 统一为……（中文）或...（英文） |
| 13 | 书名号与斜体混用 | 低 | 中文书名有时用斜体代替书名号 | 中文用书名号《》，英文用斜体 |
| 14 | 顿号与逗号混用 | 低 | 并列成分之间标点不统一 | 中文并列用顿号，英文用逗号 |
| 15 | 序号后标点不统一 | 低 | (1) 与 1. 与 ① 混用 | 统一为一种编号格式 |

### 修正原则

- **只修正明确的符号错误**，不改动语义
- 不确定是否为错误的情况（如中英文混排中空格的取舍），标记为"建议复核"而非直接修改
- 修正范围覆盖全文，不仅仅是正文：标题、摘要、关键词、脚注、图表题注、参考文献、附录、作者信息

## 三线表标准（学术论文必需）

中国学术论文的表格必须使用三线表样式：仅保留三条水平线，无竖线、无其他横线。

### 边框规格

| 边框 | 粗细 | Word XML size 值 | 说明 |
|------|------|-----------------|------|
| 顶线 (w:top) | 1.5pt | `size="12"` | 表格最上方粗线 |
| 栏目线 (w:insideH) | 0.75pt | `size="6"` | 仅表头行下方的细线 |
| 底线 (w:bottom) | 1.5pt | `size="12"` | 表格最下方粗线 |
| 其余所有 | none | `w:val="none"` | 左右竖线、行间横线全部去掉 |

### XML 示例

```xml
<w:tblBorders>
  <w:top w:val="single" w:sz="12" w:space="0" w:color="000000"/>
  <w:left w:val="none" w:sz="0" w:space="0" w:color="000000"/>
  <w:bottom w:val="single" w:sz="12" w:space="0" w:color="000000"/>
  <w:right w:val="none" w:sz="0" w:space="0" w:color="000000"/>
  <w:insideH w:val="single" w:sz="6" w:space="0" w:color="000000"/>
  <w:insideV w:val="none" w:sz="0" w:space="0" w:color="000000"/>
</w:tblBorders>
```

### 检测要点

- `w:insideV` 必须为 `none`（无竖线）
- 表头行下方的 `w:insideH` 为 `size="6"`，其余行间横线为 `none`
- 表头单元格不加背景色（`w:shd w:val="clear"`）
- 表题在表格上方，不在下方

## 块级公式排版标准

学术论文中的块级公式采用三列无边框表布局，实现公式居中 + 编号右对齐：

```
┌──────────┬──────────────────────────┬──────────┐
│  1cm 留白 │   公式 (居中, OMML)       │  (n) 右齐 │
│  567 DXA  │        7936 DXA          │ 567 DXA  │
└──────────┴──────────────────────────┴──────────┘
  整个表格无边框；单倍行距
```

### 插入方式

```bash
# 用 formula.py 插入（依赖 pandoc >= 2.0）
python scripts/formula.py unpacked/ "LaTeX表达式" 编号 --anchor "锚文本"

# 仅输出 XML 片段（不修改文件）
python scripts/formula.py --latex "E=mc^2" --number 1
```

### 行内公式

行内数学符号（如 α、β、Q*）直接作为文本处理，设置斜体即可。不需要嵌入公式编辑器对象。

### 引文上标

正文中的 `[1]`、`[2]` 等引文标记应设为上标格式（`w:vertAlign w:val="superscript"`）。
