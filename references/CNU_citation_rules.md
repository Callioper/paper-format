## 零、`[国籍]` 标注规则（外文译著专用）

当参考文献列表中引用的是**外国作者的中文译著**时，须在作者姓名前加 `[国籍]` 标注。脚注引用不加（脚注沿用原始格式）。

**常用标注对照**

| 标注 | 适用国籍 |
|------|---------|
| `[美]` | 美国 |
| `[英]` | 英国 |
| `[法]` | 法国 |
| `[德]` | 德国 |
| `[意]` | 意大利 |
| `[俄]` | 俄国/苏联 |
| `[日]` | 日本 |
| `[斯洛文尼亚]` | 斯洛文尼亚（写全称，无简称） |

**格式**
```
[国籍]作者：《书名》，译者译，出版地：出版社，年份。
```

**示例**
```
[法]阿兰·巴迪欧：《存在与事件》，蓝江译，南京：南方传媒出版社，2019年。
[美]弗雷德里克·詹姆逊：《政治无意识》，王逢振等译，北京：中国社会科学出版社，1999年。
```

**判断依据**：根据作者国籍判断，而非出版语言。国籍不明时查 WorldCat 或作者简介，仍无法确认时保留待人工核实（不要乱加）。

## 一、中文文献

### 1. 专著（著作）

**基本格式**
```
作者：《书名》，出版地：出版社，年份，第X页。
```

**出版地完整性**：出版社名称**必须**包含城市前缀（`出版地：出版社`），不能只写出版社名称。
- ❌ `江苏人民出版社` → ✅ `南京：江苏人民出版社`
- ❌ `商务印书馆` → ✅ `北京：商务印书馆`
- ❌ `上海译文出版社` → ✅ `上海：上海译文出版社`

检测时，凡参考文献中出版社名称前没有 `城市：` 格式的，视为 P1 错误，自动补全（参考出版社常见注册地）。

**有责任方式（非"著"）**
```
谢兴尧整理：《荣庆日记》，西安：西北大学出版社，1986年，第175页。
任继愈主编：《中国哲学发展史（先秦卷）》，北京：人民出版社，1983年，第25页。
```

**有译者**
```
实藤惠秀：《中国人留学日本史》，谭汝谦、林启彦译，香港：中文大学出版社，1982年，第11—12页。
```

**多出版社**
```
金冲及主编：《周恩来传》，北京：人民出版社、中央文献出版社，1989年，第9页。
```

**出版时间不详**
```
狄葆贤：《平等阁笔记》，上海：有正书局，出版时间不详，第8页。
```

### 2. 析出文献（书中章节/文章）

**基本格式**
```
作者：《章节名》，编者编：《书名》，出版地：出版社，年份，第X—X页。
```

**文集责任者与析出文献责任者相同时，省去文集责任者**
```
鲁迅：《中国小说的历史的变迁》，《鲁迅全集》第9册，北京：人民文学出版社，1981年，第325页。
```

### 3. 期刊论文

**基本格式**
```
作者：《文章题名》，《期刊名》年份第X期。
```

**同名期刊注出版地**
```
费成康：《葡萄牙人如何进入澳门问题辨证》，《社会科学》（上海）1999年第9期。
```

### 4. 学位论文

**基本格式**
```
作者：《题名》，博士学位论文，学校名称，年份，第X页。
```

### 5. 电子文献

```
作者：《题名》，更新日期，URL，访问日期。
```

### 6. 再次引证（简化格式）

同一文献第二次及以后引用时：
```
作者：《书名》，第X页。
```

## 二、英文文献

### 1. 专著

**基本格式**
```
Author, *Title*, Place: Publisher, Year, p. X.
```

### 2. 译著

```
Author, *Title*, trans. Translator Name, Place: Publisher, Year, p. X.
```

### 3. 期刊析出文献

```
Author, "Article Title," *Journal Name*, vol. X, no. X (Month Year), pp. X-X.
```

### 4. 文集析出文献

```
Author, "Chapter Title," in Editor Name, ed., *Book Title*, Place: Publisher, Year, p. X.
```

### 5. 再次引证（简化格式）

```
Author, *Short Title*, p. X.
```

## 三、标点与格式细节

| 情形 | 中文 | 英文 |
|------|------|------|
| 书名 | 《书名》 | *斜体* |
| 文章题名 | 《文章题名》 | "引号" |
| 页码单页 | 第X页 | p. X |
| 页码范围 | 第X—X页（全角破折号） | pp. X-X |
| 引用结束 | 。 | . |

## 四、⚠️ P1/P2/P3 严重程度分类

### P1（必须修复）
- 缺少必填字段（作者/题名/年份/出版社）
- 中文书名未使用《》，英文书名未使用斜体

### P2（应当修复）
- 页码范围使用了连字符 `-` 而非全角破折号 `—`
- 标点符号错误

### P3（建议修复）
- 再次引证未使用简化格式
- 引用键有拼写风险
