# CNU《外国文学评论》注释体例（2024修订版）完整格式规则

来源：《外国文学评论》注释体例（修订版）2024年第2期 + cnu.csl

---

## 一、中文文献

### 1. 专著（著作）

**基本格式**
```
作者：《书名》，出版地：出版社，年份，第X页。
```

**有责任方式（非"著"）**
```
谢兴尧整理：《荣庆日记》，西安：西北大学出版社，1986年，第175页。
任继愈主编：《中国哲学发展史（先秦卷）》，北京：人民出版社，1983年，第25页。
```

**有译者**
```
实藤惠秀：《中国人留学日本史》，谭汝谦、林启彦译，香港：中文大学出版社，1982年，第11—12页。
```

**多出版社**
```
金冲及主编：《周恩来传》，北京：人民出版社、中央文献出版社，1989年，第9页。
```

**出版时间不详**
```
狄葆贤：《平等阁笔记》，上海：有正书局，出版时间不详，第8页。
```

### 2. 析出文献（书中章节/文章）

**基本格式**
```
作者：《章节名》，编者编：《书名》，出版地：出版社，年份，第X—X页。
```

**文集责任者与析出文献责任者相同时，省去文集责任者**
```
鲁迅：《中国小说的历史的变迁》，《鲁迅全集》第9册，北京：人民文学出版社，1981年，第325页。
```

### 3. 期刊论文

**基本格式**
```
作者：《文章题名》，《期刊名》年份第X期。
```

**同名期刊注出版地**
```
费成康：《葡萄牙人如何进入澳门问题辨证》，《社会科学》（上海）1999年第9期。
```

### 4. 学位论文

**基本格式**
```
作者：《题名》，博士学位论文，学校名称，年份，第X页。
```

### 5. 电子文献

```
作者：《题名》，更新日期，URL，访问日期。
```

### 6. 再次引证（简化格式）

同一文献第二次及以后引用时：
```
作者：《书名》，第X页。
```

## 二、英文文献

### 1. 专著

**基本格式**
```
Author, *Title*, Place: Publisher, Year, p. X.
```

### 2. 译著

```
Author, *Title*, trans. Translator Name, Place: Publisher, Year, p. X.
```

### 3. 期刊析出文献

```
Author, "Article Title," *Journal Name*, vol. X, no. X (Month Year), pp. X-X.
```

### 4. 文集析出文献

```
Author, "Chapter Title," in Editor Name, ed., *Book Title*, Place: Publisher, Year, p. X.
```

### 5. 再次引证（简化格式）

```
Author, *Short Title*, p. X.
```

## 三、标点与格式细节

| 情形 | 中文 | 英文 |
|------|------|------|
| 书名 | 《书名》 | *斜体* |
| 文章题名 | 《文章题名》 | "引号" |
| 页码单页 | 第X页 | p. X |
| 页码范围 | 第X—X页（全角破折号） | pp. X-X |
| 引用结束 | 。 | . |

## 四、⚠️ P1/P2/P3 严重程度分类

### P1（必须修复）
- 缺少必填字段（作者/题名/年份/出版社）
- 中文书名未使用《》，英文书名未使用斜体

### P2（应当修复）
- 页码范围使用了连字符 `-` 而非全角破折号 `—`
- 标点符号错误

### P3（建议修复）
- 再次引证未使用简化格式
- 引用键有拼写风险
